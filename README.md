# Project 07: CI Validation for Terraform

## Objective
Automate Terraform code validation using GitHub Actions.

## Tools Used
- Terraform
- Git
- GitHub
- GitHub Actions
- AWS Provider

## Implementation
- Configured Terraform and AWS provider versions.
- Created an example AWS S3 bucket configuration.
- Configured GitHub Actions to run automatically on pushes and pull requests.
- Added Terraform formatting, initialization, and validation checks.
- No AWS infrastructure is deployed by this project.

## CI Pipeline Checks
1. Terraform Format Check
2. Terraform Initialization
3. Terraform Validation

## Deliverables
- GitHub repository containing Terraform configuration.
- GitHub Actions workflow.
- Workflow status badge.
- Successful pipeline screenshot.
